EcoCity Heat Planner

An interactive simulation dashboard that models urban heat island effects and tests mitigation strategies like green roofs, cool pavements, and tree planting in real time.

Open project details
  • Built for the Craft N Code hackathon organized by Cyber Space Club, Manipal University Jaipur in collaboration with Techfest IIIT Bhubaneswar — Round 00 (online round), results pending.

Space / GISNext.js + Prisma + Python

Lunar Ice Intelligence

A mission-planning prototype that fuses Chandrayaan-2 radar data, terrain products, and illumination proxies to rank candidate subsurface-ice targets for lunar landing site selection.

Open project details
  • Originally built for ISRO's Bharatiya Antariksh Hackathon 2026 — Problem Statement 8: Detection and Characterization of Subsurface Ice in Lunar South Polar Regions Using Chandrayaan-2 Radar and Imagery Data.
  • Evolved into a 2-month project-based learning build covering Prisma ORM, Python geospatial processing, and full-stack Next.js development.
  • Fused Chandrayaan-2 DFSAR radar evidence, TMC-2 terrain products, OHRC footprint/hazard-readiness outputs, illumination/cold-trap proxies, and NASA LOLA validation.
  • Implemented CPR/DOP threshold gating (CPR > 1, DOP < 0.13), Faustini/F2 reference modeling, and solar-aware A* traverse routing from landing zone to science target.
  • Built top-5m ice-volume scenarios at 3%, 8%, and 15% assumed fractions, with validation gate readiness tracking and scientific honesty panels.
  • Deployed on Render with Next.js auth shell, Prisma database layer (JSON fallback for local dev), and a same-origin evidence dashboard.

AI energy tool Next.js + Supabase + Gemini

ShockProof

An AI-powered smart meter tariff guard that helps Indian households understand meter readings, projected usage, bill risk, and practical ways to avoid expensive slab jumps.

Open project details
  • Built for the INDIA RUNS 2026 Ideathon, Challenge 3: Improve Everyday Life with AI, as part of team Noble Dawn.
  • Implemented a protected dashboard flow where users can upload or capture meter photos/videos, store captures in Supabase Storage, and track reading history.
  • Integrated Gemini OCR to extract cumulative kWh readings, then calculated current usage, projected month-end usage, next slab distance, estimated bill, and bill-risk level.
  • Generated household-friendly Gemini advice tied to projection numbers, tariff slabs, and practical load actions before usage crosses expensive thresholds.
  • Used Supabase Auth, Database, Storage, Realtime, RLS policies, Rajasthan tariff seed data, and Vercel deployment for a realistic AI product workflow.
